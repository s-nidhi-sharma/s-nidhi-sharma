## Nidhi Sharma

Product security architect working on **trust in software and AI supply chains** — how we know where code and models came from, who built them, and whether they can be trusted.

**Research focus**
- AI supply-chain security: model provenance, signing and attestation of model weights and training data, AI-BOM
- Security of AI agents: identity, authorization and containment for LLM agents
- Post-quantum migration for signing infrastructure and long-lived devices

**Background**
- 16 years in systems and security engineering, from Linux kernel storage and embedded drivers to hypervisor and Windows kernel security
- Architected an enterprise product-signing platform for firmware and software, and authored its post-quantum migration proposal
- Designed device trust end to end: secure boot, secure update (FIT images, OSTree), factory provisioning
- Built protocol fuzzing for industrial (ISA/IEC 62443) certification
- Ex-VMware: Windows kernel security for AppDefense; certificate-chain validation on OpenSSL X.509
- 8 U.S. patents across hypervisor security, device tamper detection and attack monitoring
